# CX language

The compiler repository owns the detailed [language reference](/language/reference). It describes the syntax and behavior implemented by the checked-in compiler revision and calls out unsupported constructs. The checked-in ANTLR grammar provides additional syntax detail.

CX and its generated-code ABI are experimental. The reference describes current implementation behavior; it is not a source or binary compatibility promise.
