# Visual Studio Code

The [CX extension](https://marketplace.visualstudio.com/items?itemName=cx-pl.cx) provides syntax highlighting and commands to build, run, and debug CX files. Its current feature and debugger limits are described in the [extension README](https://github.com/cx-pl/vscode-extension/blob/7b2eb4ac41fec5bdf34a0aeb3f6779940180b4d1/README.md).

You need the CX compiler, `cxcore`, CMake, and a native compiler. The extension currently documents debugging with the Microsoft C/C++ extension and MSVC on Windows; see its README for configuration and limitations.
