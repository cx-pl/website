# Packages with cxpm

`cxpm` is the CX package manager CLI. Its checked-in documentation describes YAML `.cxproj` files, ZIP packages, local and HTTP feeds, dependencies, lock files, and native library requirements.

The package manager and its web catalog are still evolving. Start with the [cxpm README](https://github.com/cx-pl/cxpm/blob/c47d720a30fb9a499509bbd439f4989a2f0e90ed/README.md) and verify current instructions against your checkout. No public package-feed URL is assumed by this site.
