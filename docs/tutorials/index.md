# Learn CX

Follow the lessons in order. Each one uses small CX programs and links to the corresponding full example where one is available. CX is changing, so check the experimental notes when a feature is described as partial.

1. [Hello World](./hello-world) — compile and run a CX program.
2. [Values and control flow](./values-and-control-flow) — types, variables, branches, loops, and arrays.
3. [Types and objects](./types-and-objects) — classes, structs, interfaces, and properties.

The checked-in examples are the source for sample programs. Tutorial code is illustrative; run it with the compiler and runtime revisions on the [tested revisions page](/project/revisions).
