# About CX

CX is an experimental programming language and native compiler project. Its compiler is written in C# and emits C and CMake build files. The standard library and runtime are implemented in C and CX. Current development also includes a package manager and Visual Studio Code support.

The language, runtime ABI, libraries, and tooling are changing. The project does not promise binary compatibility, and some features or platform paths are incomplete. Use the [tested revisions](/project/revisions) and the repository documentation when evaluating a feature.

Reference documents and the syntax grammar are reproduced from repositories under their respective licenses. See [source license notices](/project/attributions).

## Contributing

The compiler, runtime, examples, package manager, and editor extension live in separate repositories in the [cx-pl GitHub organization](https://github.com/cx-pl). Open issues or pull requests in the repository that owns the code or documentation. Include the CX, runtime, operating system, and native toolchain revisions when reporting a build or runtime issue.
