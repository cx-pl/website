# Standard library

CX's standard library and runtime are developed in the [cxcore repository](https://github.com/cx-pl/cxcore). The pages below are imported snapshots of its checked-in runtime contracts and ABI notes.

The runtime includes core types, strings, arrays, collections, memory operations, threading, and native interoperability. Consult the [runtime contracts](/generated/standard-library-contracts) for ownership rules and platform details, and the [runtime ABI notes](/generated/runtime-abi) for generated-code compatibility requirements.

Both runtime behavior and generated-code ABI are experimental. Check the source revision at the top of each imported page before relying on a detail.
